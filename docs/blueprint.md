# **App Name**: Hobo Livings

## Core Features:

- Location Search: Search for properties by city, location, or landmark with autocomplete.
- Multi-Criteria Filtering: Filter properties by price range, location radius, property type (Boys/Girls/Co-ed), category (Hostel, PG, Room, Hotel), and amenities.
- Property Listings: Display search results as property cards with a photo, title, price, location, key amenities, and 'Book Now' button.
- Property Details Page: Display full property details including a photo gallery, description, amenities list, map, and commute info.
- Booking Inquiry Flow: Implement a 'Book Now' flow that prompts login/signup, then sends an inquiry to the property owner/admin.
- Saved Listings & Reviews: Enable users to save favorite properties and write/read reviews. Show related articles, blogs using LLM.
- FAQ Chatbot: Tool for answering students FAQs about property details in chatbot format

## Style Guidelines:

- Primary color: Bold red (#E63946) to resonate with energetic college-goers.
- Background color: Light pink (#F1FAEE), a desaturated tint of red to complement the primary color.
- Accent color: Light orange (#F4A261), an analogous color to add contrast.
- Headline font: 'Space Grotesk' (sans-serif) for a modern, techy feel.
- Body font: 'Inter' (sans-serif) for a clean, readable interface.
- Use clear, concise icons for amenities and property features.
- Design a mobile-first, responsive UI with property cards and clear CTAs.
